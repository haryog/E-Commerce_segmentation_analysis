# 📊 User Segmentation Analysis on E-Commerce X Using K-Modes Clustering

## Problem Statement

In this project, I will analyze **K-Modes Clustering** to explore how user segmentation can be performed on E-Commerce X based on two key aspects:

### 1. Demographic Segmentation

This segmentation analysis aims to support **advertising strategies** and **product recommendations** tailored to specific customer groups.

Goals:
- Helps build **buyer/customer personas** → *personalized marketing*
- Supports **targeted advertising strategies** (e.g., *Impulsive Young Professionals* or *Promo-Savvy Buyers*)

### 2. Behavioral Segmentation

This analysis focuses on how users interact with products and services on the platform.

Goals:
- Understands **behavioral patterns** within each segment
- Identifies **loyal customer segments** → Enables appropriate *promotions or special offers*

---

## 🧠 Data Analysis Method

- Utilizes the **K-Modes Clustering** algorithm, suitable for **categorical data**
- Segments users based on **demographic** and **behavioral attributes**
- Visualizes clustering results for better interpretation

---

> 📌 *K-Modes is a variation of K-Means designed specifically for categorical data. It uses the mode as the cluster center and calculates dissimilarity based on the number of mismatched categories.*
